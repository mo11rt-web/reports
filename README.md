# متابعة المشاريع

## بناء مثبت Windows من GitHub

1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد.
2. من تبويب **Actions** شغّل **Build Windows Installer** ثم اضغط **Run workflow**.
3. بعد انتهاء البناء، حمّل ملف `.exe` من قسم **Artifacts**.
4. لإصدار دائم داخل **Releases**، غيّر رقم `version` في `package.json` ثم نفّذ:

```bash
git add .
git commit -m "release 1.4.0"
git tag v1.4.0
git push origin main --tags
```

سيبني GitHub المثبت ويرفعه تلقائيًا إلى Releases.

## التحديث فوق النسخة القديمة

شغّل مثبت الإصدار الجديد مباشرة، ولا تحذف النسخة القديمة أولًا. استخدم نفس مجلد التثبيت السابق. المثبت يستبدل ملفات البرنامج فقط، أما بيانات المشاريع والتقارير فهي في بيانات المستخدم المحلية داخل `%APPDATA%` وتبقى محفوظة.

> مهم: لا تغيّر `appId` ولا تحذف `localStorage` من التطبيق، ولا تستخدم خيار حذف بيانات التطبيق عند إزالة التثبيت.

## ملاحظات على التقرير والطباعة

- عند الضغط على **حفظ التعديلات** أو **طباعة** يطلع مربع لتحديد التاريخ: من / إلى / تاريخ الإصدار.
- الخط المستخدم Calibri. حروف Calibri لاتينية وأرقام فقط، فالحروف العربية تظهر بخط Segoe UI (الاحتياطي) — هذا سلوك طبيعي للخط.
- البناء يعتمد على `package-lock.json` (الأمر `npm ci`)، فلا تحذفه من المستودع.

## تنسيق نص التقرير

- بشاشة "التقرير الأسبوعي"، اضغط ✏️ على أي مشروع لتحرير نقاطه، يطلع شريط تنسيق (غامق، مائل، تحته خط، نوع الخط، الحجم، لون النص، لون التظليل، محاذاة، قوائم).
- حدد النص المطلوب تنسيقه أولاً بالماوس، ثم استخدم الشريط — تماماً مثل الوورد.
- التنسيق يُحفظ مع التقرير ويظهر بالطباعة/PDF.
