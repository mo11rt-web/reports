# نظام متابعة المشاريع

تطبيق لمتابعة حالة المشاريع أسبوعياً، مع:
- سجل تحديثات أسبوعي لكل مشروع (نقاط ملوّنة: عادي / مهم أخضر / مهم أحمر)
- حالة دفعات FAB اختيارية لكل مشروع (يمكن تعطيلها للمشاريع غير المرتبطة ببنك)
- استيراد ذكي: الصق تقرير نصي كامل بأي صيغة (أرقام، تعداد نقطي، أو "اسم: ملاحظة") ويوزّعه تلقائياً على كل مشروع
- تقرير أسبوعي قابل للتحرير المباشر (نص، لون، إضافة/حذف نقاط) قبل الحفظ أو الطباعة
- بنود إضافية حرة تُضاف بآخر التقرير (ملاحظات عامة وغيرها)
- سجل تاريخي لكل تقرير مطبوع، مرتب بالتاريخ

## بنية المشروع

```
project/
├── app/                  ← الموقع نفسه (HTML + CSS + JS)
│   ├── index.html
│   ├── style.css
│   └── app.js
├── main.js               ← نقطة دخول تطبيق Electron (سطح المكتب)
├── package.json          ← إعدادات المشروع وبناء الـ exe
├── .github/workflows/    ← يبني ملف EXE تلقائياً على GitHub
└── README.md
```

## طريقة 1: استخدامه كموقع فقط (بدون تنصيب)

افتح `app/index.html` مباشرة بأي متصفح (Chrome/Edge). البيانات تُحفظ محلياً
داخل المتصفح على نفس الجهاز (localStorage) وتبقى محفوظة بين مرات الفتح.

> ملاحظة: التخزين مرتبط بالمتصفح والمسار الذي تفتح منه الملف. إذا نقلت
> الملف لمجلد آخر أو فتحته من متصفح مختلف، ستبدأ ببيانات جديدة (لأن كل
> متصفح/مسار له تخزين منفصل). لضمان استمرارية البيانات بأفضل شكل، يُفضّل
> استخدام نسخة تطبيق سطح المكتب (Electron) بالأسفل.

## طريقة 2: تجربته كتطبيق سطح مكتب على جهازك

يتطلب تثبيت [Node.js](https://nodejs.org) مرة واحدة على جهازك، ثم:

```bash
npm install
npm start
```

سيفتح التطبيق كنافذة مستقلة (بدون متصفح) وبياناته محفوظة بين مرات التشغيل.

## طريقة 3: الحصول على ملف EXE جاهز عبر GitHub (تلقائياً)

1. أنشئ مستودع (Repository) جديد فاضي على GitHub.
2. ارفع كل ملفات هذا المشروع (بنفس البنية أعلاه) إلى المستودع، على فرع `main`.
3. بمجرد الرفع (push)، سيعمل GitHub Actions تلقائياً ويبني ملف EXE (يأخذ
   بضع دقائق). تقدر تتابعه من تبويب **Actions** بالمستودع.
4. بعد اكتمال البناء (علامة ✔ خضراء)، افتح تفاصيل التشغيل (run) واضغط على
   **project-tracker-windows** أسفل قسم **Artifacts** لتحميل ملف مضغوط
   يحتوي على ملف الإعداد (installer) الخاص بويندوز.
5. أو من جهازك مباشرة: بعد `npm install`، شغّل:
   ```bash
   npm run build
   ```
   وستجد ملف EXE داخل مجلد `dist/`.

## تعديل البيانات أو الشكل لاحقاً

- بيانات المشاريع والتقارير كلها داخل الكود بمتغيرات JavaScript
  (`app/app.js`) وتُحفظ فعلياً بالمتصفح/التطبيق وليس بملف خارجي.
- ملف `app/style.css` يحتوي كل الألوان والأشكال — غيّر متغيرات
  `:root` بالأعلى لتغيير الألوان العامة بسهولة.
- لإضافة شعار الشركة: ضع صورة داخل مجلد `app/` واستبدل رمز SVG داخل
  `index.html` بوسم `<img src="logo.png">`.

## استيراد التحديثات الأسبوعية دفعة واحدة

من تبويب "التقرير الأسبوعي" اضغط "📋 استيراد نقاط من نص"، والصق نصاً بأي
من هذه الصيغ (يمكن تجهيزه وتحسين صياغته عبر أي أداة ذكاء اصطناعي أولاً
ثم لصقه هنا) — النظام يتعرف عليها تلقائياً:

```
1. اسم المالك
- نقطة عادية
! نقطة مهمة تظهر باللون الأحمر
+ نقطة إيجابية تظهر باللون الأخضر

اسم مالك آخر
- تحديث آخر

اسم مالك ثالث: ملاحظة بسطر واحد
```

اضغط "تحليل النص" للتأكد من مطابقة كل اسم لمشروعه الصحيح (يمكنك تصحيح
المطابقة يدوياً من القائمة المنسدلة)، ثم "تطبيق على السجل".

## تحرير التقرير قبل الطباعة

بعد الضغط على "معاينة التقرير"، يظهر بجانب كل مشروع زر قلم ✏️ — اضغطه
لتحرير نص أي نقطة أو لونها أو حذفها/إضافة نقاط جديدة مباشرة داخل
المعاينة. زر "💾 حفظ التعديلات" يحفظها بشكل دائم ويسجّل نسخة بالسجل،
وزر "🖨 طباعة" يفعل نفس الشيء ثم يفتح نافذة الطباعة.
